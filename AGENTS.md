# Exact MF example

Read the Exact checkout's `docs/start-here.md` before editing the app.
Use the Exact revision recorded in README.md. Keep generated native dependencies on that checkout.
Do not put private signing keys in this repository or public snapshots.
Do not replace signed generation admission or upstream MF lifecycle calls with host version branches.
Run the focused validation after bridge changes. Build the simulator HOST app without launching it unless the user requests device work.
